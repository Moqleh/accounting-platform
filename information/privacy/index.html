نطاق هذه الصفحة

تشرح هذه الصفحة سلوك النسخة العامة المنشورة على GitHub Pages. عند تشغيل نسخة متصلة بخادم، تُرسل عمليات الحسابات إلى ذلك الخادم وتخضع بياناتها لإدارة الجهة المشغلة. آخر تحديث: 12 سبتمبر 2026.

ما الذي يحفظه المتصفح؟

تستخدم المعاينة التخزين المحلي لحفظ بيانات العمليات التجريبية، والجلسة، والشركة المختارة، وتفضيل اللغة، وقيم تحقق كلمة مرور المعاينة عند تغييرها. لا تُشفّر سجلات المعاينة المخزنة محليًا؛ تجنب إدخال بيانات حقيقية أو حساسة.

الاستضافة والتواصل

لا تتضمن الواجهة الحالية أدوات إعلانات أو تحليلات مضافة من طرفنا. قد تجمع GitHub معلومات تقنية عن الزيارات، ومنها عنوان IP لأغراض الأمان. عند مراسلتنا بالبريد، تُعالج رسالتك ومعلومات تواصلك للرد عليها عبر مزود البريد.

الاحتفاظ والتحكم

تبقى بيانات المعاينة في المتصفح حتى حذفها أو إزالتها بواسطة المتصفح. تسجيل الخروج يزيل الجلسة والشركة المختارة، ولا يحذف سجلات المعاينة. صفحة إدارة البيانات تشرح خياراتك؛ لا نمسح سجلاتك تلقائيًا عند فتح هذه الصفحات.
